# GOES Signatures for Flood Prediction

## Data

Download the ground source data and place it in the `data/` directory:

```bash
wget -P data/ "https://zenodo.org/records/18647054/files/groundsource_2026.parquet?download=1" -O data/groundsource_2026.parquet
```

Or manually download from [Zenodo](https://zenodo.org/records/18647054/files/groundsource_2026.parquet?download=1) and save as `data/groundsource_2026.parquet`.
